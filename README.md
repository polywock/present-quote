
Simple project: 
## https://polywock.github.io/present-quote

1. Click on text to change quote to whatever you want. 
2. Copy the URL and it will open a small webpage with just the quote.

If you use the Global Speed extension, you can create a URL rule that automatically opens this quote page with a message of your choice. For example, when you visit distracting websites, Global Speed can trigger a motivational quote to remind you of your goals.

Example JavaScript code for Global Speed URL rule:

```javascript
window.location.href = "https://polywock.github.io/present-quote/?quote=Go back to work you lazy piece of trash!"
```
